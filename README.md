# Kyon2

Preview builds of Kyon2 for macOS (Apple silicon and Intel, macOS 11 or later),
signed and notarised.

```sh
brew install --cask kyon-sh/kyon/kyon2
```

Or download the disk image from the latest entry under
[Releases](https://github.com/kyon-sh/kyon2/releases). Kyon2 installs as
`Kyon2.app` and does not replace an existing Kyon.

To update:

```sh
brew upgrade --cask kyon2
```
